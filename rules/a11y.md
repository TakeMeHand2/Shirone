# 无障碍与键盘交互规范

> Shirone 原子的无障碍（a11y）与键盘交互约定。
> 质量闸门：axe-core（WCAG 2.1 AA）light/dark 双模式 0 违规。
> 配套：`tests/site/a11y.spec.ts`（真实页面 light/dark 双模式扫描）、
> `tests/site/swup-a11y.spec.ts`（站内导航后的焦点与播报）。

---

## 1. 语义与 ARIA

### 1.1 原生语义优先

能用原生元素就用原生元素，不要用 `<div>` 自造：

| 场景 | 正确元素 |
|---|---|
| 开关 | `<input type="checkbox">` + 自绘（Switch） |
| 复选 | `<input type="checkbox">`（Checkbox） |
| 单选 | `<input type="radio">`（RadioButton、SegmentedButton 单选） |
| 按钮 / 可点击卡片 | `<button>`（Card onClick） |
| 导航链接 | `<a href>`（Button href、PostCard 标题） |
| 对话框 | `role="dialog"` + `aria-modal`（Dialog/SheetSide/AlertDialog） |
| 菜单 | `role="menu"` / `role="listbox"` + `aria-activedescendant`（Select） |

### 1.2 可访问名称

- 有可见文字：用文字作为名称（`<button>保存</button>`）；
- 纯图标控件：`aria-label`（IconButton、FAB 图标模式、折叠的 NavigationRail item）；
- label 与控件关联：`<label>` 包裹，或 `aria-labelledby`（Select 的 combobox 名称来自 label）。

### 1.3 状态同步

| 状态 | 属性 |
|---|---|
| 选中 / 按下 | `aria-pressed`（ToggleButton、filter Chip）、`aria-current`（NavigationBar item、PagePagination 激活页）、`aria-selected`（Tab） |
| 展开 | `aria-expanded`（Menu、SearchBar、ExposedDropdownMenu） |
| 隐藏不可聚焦 | `inert`（FABMenu/SearchBar 收起时的内容区） |
| 装饰元素 | `aria-hidden="true"`（AccentBar、图标、分隔线） |

## 2. 键盘交互约定

### 2.1 通用

- 原生控件自带键盘语义（`<button>` 的 Enter/Space、`<input>` 的方向键），优先复用；
- 自绘控件补齐键盘（Tab 移动、方向键选择、Esc 关闭、Home/End 首尾）。

### 2.2 各组件键盘清单（已锁定）

| 组件 | 键盘行为 |
|---|---|
| Dialog / AlertDialog / SheetSide | 打开聚焦容器，Tab 焦点陷阱循环，Esc 关闭，关闭后焦点返还触发元素 |
| Select | Enter/Space/方向键展开，方向键/Home/End 移动，Enter 选中，Esc 关闭，首字母 typeahead |
| Tabs | 方向键 + Home/End 移动（焦点与激活跟随） |
| Autocomplete | ↑↓ 导航 + `aria-activedescendant`，Enter 选中，Esc 关闭 |
| SegmentedButton | 单选段方向键移动（radio 语义），多选 Space 切换 |
| Checkbox / Switch | Space 切换，disabled 不可交互 |
| Card（可点击） | Enter/Space 触发，disabled 不可交互 |
| Tooltip | hover 延迟显示，focus 立即显示，注入 `aria-describedby` |
| SearchView | 全屏 Esc 关闭，打开自动聚焦输入框，建议 ↑↓ + Enter 选择 |
| SearchBar | Esc 收起并失焦，ArrowDown 焦点移入建议 |
| Menu | Esc / 点击外部关闭，互斥单开 |
| Slider | 方向键 / PageUp/PageDown / Home/End 步进 |
| TimePicker | 键盘切换输入模式，输入自动跳格 |

## 3. 焦点管理约定

- **打开后聚焦**：Dialog/SheetSide/SearchView 打开时聚焦容器或输入框；
- **焦点陷阱**：模态组件（Dialog/SheetSide）内 Tab 循环，不逃逸到背景；
- **关闭后返还**：关闭后焦点返回到触发元素（官方 Modal 行为）；
- **inert**：非活动内容区（FABMenu 收起菜单项、SearchBar 收起建议）加 `inert`，不可聚焦、从无障碍树隐藏。

### 3.1 Swup 路由切换后的焦点与播报（站内导航）

站内导航不走整页加载，`<title>` 与 DOM 都变了，但**焦点不会自己移动**。约定：

| 项 | 契约 | 落点 |
|---|---|---|
| 焦点落点 | 导航完成后焦点移到主内容容器 `#swup-container`（`<main>`，带 `tabindex="-1"`），不是 `<body>` | `Layout.astro` 的 a11y 内联脚本 |
| 焦点环 | `#swup-container` 是程序化落点、不进 Tab 序，`outline: none` 属**有意豁免** | `styles/transition.css` |
| 读屏播报 | 播报当前页标题，文案走 i18n（`a11yNavigatedTo`，`{title}` 由脚本替换） | 同上 |
| 标题来源 | **只取 Swup 容器内**的 `h1`/`h2`，取不到再退 `document.title` | 同上 |

两条硬性理由，改动前务必留意：

1. **标题必须限定在容器内查询。** Banner 的 `<h1>`（`BannerStage.astro`）在每个页面都
   存在于 DOM 中，只靠 CSS 切换可见性；文档级 `querySelector("h1")` 会永远命中它，
   播报就变成 Banner 标题而不是当前页。
2. **覆写要挂 `before("visit:end")` 而不是 `on(...)`。** Swup 4 的钩子注册表把 `on()`
   注册的处理器归入 **after** 组（跑在默认行为之后），只有 `before` 组在默认行为之前；
   用 `on` 覆写 `visit.a11y` 会静默失效。

上述行为由 `tests/site/swup-a11y.spec.ts` 锁定（含「不播报 Banner 标题」的反例断言）。

## 4. 对比度

- 正文/小字（<18.66px 非粗体，或 <24px）：对比度 ≥ **4.5:1**；
- 大字（≥24px 或 ≥18.66px 粗体）：对比度 ≥ **3:1**；
- 图标/图形（非文本）：≥ **3:1**（WCAG 1.4.11）。

文字颜色一律走 token（`--on-surface` / `--on-surface-variant` 系 + `text-90/75/50/30/25`），避免硬编码黑/白（图片覆盖层除外）。

---

## 5. 深色模式

- 所有组件必须 light/dark 双模式达标；
- 颜色一律依赖 token（跟随 `:root.dark` 切换），禁止写死浅色；
- axe 双模式扫描断言页面确实处于目标模式，防止「假通过」。

---

## 6. 动效降级

- 尊重 `prefers-reduced-motion`：过渡/动画折叠为 0.01ms，平滑滚动关闭；
- JS 驱动动画（如 FABMenu rAF）在 reduce 下直接到位；
- 装饰层特效（后续 `features/`）必须同样尊重 reduce。

---

## 7. 测试配套

新组件补 a11y 时：

1. 真实页面（或组件落地页）的语义结构变化，跑 `tests/site/a11y.spec.ts` 锁定——
   把页面加入其 `pages` 数组即自动跑 light/dark 双模式；
2. 交互组件补键盘/焦点断言：写在该组件对应的 `tests/site/<domain>.spec.ts` 里
   （`tests/atoms/` 体系已于 2026-08 移除，见 `rules/project-rules.md`）；
3. 涉及站内导航的行为，加进 `tests/site/swup-a11y.spec.ts`（焦点落点 + 播报）。

axe 违规唯一允许禁用的规则：`page-has-heading-one`（测试脚手架页面级规则，非组件契约）。

> **CI 注意**：Playwright 用例在 CI 的 `e2e` 作业里跑，但 `@visual` 组被排除
> （像素基线依赖平台）。a11y 用例不在此列，必须保持可跑。
