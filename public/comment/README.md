# 评论区角色贴纸

评论区外壳（`src/components/organisms/comment/CommentSection.astro`）用的三枚 Q 版角色贴纸。

## 素材来源

| 文件 | 用途 | 来源 |
| --- | --- | --- |
| `castorice-wink.webp` | 默认状态 | 米游社创作者 Q 版合集 |
| `castorice-shy.webp` | 鼠标悬停评论区时 | 同上 |
| `castorice-calm.webp` | 评论数为 0 时 | 同上 |

Q 版合集文章 `miyoushe.com/sr/article/62324565`（作者 UID 407777514），经检索后本地化处理。

## 后处理做了什么

原始二创图是透明底的 PNG。为了让它们在任何底色上都能"立住"，每张都烘焙了三层边：

```
墨线钥匙边（约 2px，#1f1a20） → 白色刀模（约 5px） → 原图
```

为什么需要墨线那一层：**纯白刀模在浅色卡片底上是看不见的**，贴纸形状会塌掉。
加一圈墨色钥匙边之后，亮底与暗底都能保持清晰的轮廓 —— 这也是真实印刷贴纸的做法。

> 顺带一个踩坑记录：`sharp` 的 `threshold().raw().toBuffer()` **不保证单通道**
> （实测输出 3 通道，长度 = W×H×3）。如果按单通道索引去取 alpha，整个 alpha 层会
> 整张错位，表现是"图看着对、但角落里冒出一块不透明底"。验证 alpha 是否干净，
> 唯一的可靠办法是**读四角像素的 alpha 值**，而不是看叠了背景色的自检图。

## 换素材怎么做

1. 准备透明底 PNG（越大越好，脚本会缩到 400px 宽）；
2. 确认四角是透明的（脚本会读四角并打印结果）；
3. 按下表替换：`wink` = 默认、`shy` = 悬停、`calm` = 无评论；
4. 保持文件名不变即可，组件不需要改动。

如果想改用别的角色或想调整描边粗细，后处理脚本在 `scripts/images/`（见该目录 README）。
若只是换图、不改描边风格，直接覆盖这三个 webp 文件就行。
